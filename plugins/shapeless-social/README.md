# ShapelessAI for Claude (shapeless-social)

The directory edition of ShapelessAI: drive a ShapelessAI account from Claude.

- Write, schedule and publish posts to the social accounts you connect (LinkedIn, X, Instagram,
  TikTok, YouTube, Facebook, Threads, Bluesky and more).
- Run content jobs, keep Brand Memory, and research trends.

## What it installs

- The hosted MCP server `https://shapelessai.com/mcp/social`, declared in `.mcp.json`. You sign in
  with OAuth on first use; no API key.
- The `get-started` skill, which takes a new account from install to its first drafted post.

A post waits for your approval unless you ask to publish it now. Scheduling your own posts is free
on every plan, within its daily limit; research tools spend credits at the cost each one states
(https://shapelessai.com/pricing).
